# data

Data the app ships with, so the live site does not depend on another site or a key for it.

| File | What it is | How it is made |
|---|---|---|
| `census_zip_codes.csv` | For each NYC ZIP code the housing tools use (183 ZIP codes): residents, households, renter households, median household income (dollars a year) and median rent (rent plus utilities, dollars a month), from the US Census Bureau's American Community Survey, 5-year data for 2020-2024, tables B01003, B11001, B25003, B19013 and B25064. Households and renter households are the weights for combining several ZIP codes' income and rent medians. `median_household_income_at_cap` and `median_rent_at_cap` say "yes" where the median is the Census Bureau's top value (250001 means $250,000 or more, 3501 means $3,500 or more). A blank means the Census Bureau published no figure. `compare_neighborhoods` in `neighborhoods.py` reads it, and shows a capped median as "$3,500 or more" (never as 3501). | Built by `build_census_zip_codes.py`. Do not edit it by hand. |
| `nyc_figures.json` | The same figures `compare_neighborhoods` gives for a neighborhood, for New York City as a whole, so each neighborhood's figure can be shown next to NYC's: apartments, open class C violations, tenant problems in the last 12 months, buildings filing and reporting bedbugs, first rat inspections and those finding rats, crimes and felonies reported this year, and the Census figures for New York city itself (Census place 51000). With the date it was counted, the start of its 12 months and the date its crime counts run through. `neighborhoods.py` reads it. NYC's housing figures are not shown once the file is more than 31 days old (`NYC_FIGURES_MAX_AGE_DAYS`), its crime figures not when their period differs from the live crime data, and its Census figures not when the survey differs from the ZIP code file. | Built by `build_nyc_figures.py`. Do not edit it by hand. |
| `build_nyc_figures.py` | Counts the whole city with the same conditions `neighborhoods.py` uses for a neighborhood (each count takes the city's site up to 40 seconds, which is why it is done once), and asks the Census Bureau for New York city's figures. Needs the Census key like the script below. | Rerun at least once a month, when the NYPD publishes a new quarter, and after rebuilding the Census file. |
| `build_census_zip_codes.py` | Downloads the five Census tables for every ZIP code in the country, keeps the NYC ones and marks the capped medians. Needs a free Census key (https://api.census.gov/data/key_signup.html) in the `CENSUS_API_KEY` environment variable or in `~/.census_api_key`; the key is never written to the file. | Rerun once a year, after the Census Bureau's December release, with `SURVEY_YEAR` here and `CENSUS_SURVEY_YEAR` in `neighborhoods.py` both moved to the new year, then rebuild `nyc_figures.json`. |
